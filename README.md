## ✨ Sobre o Projeto

Este repositório é o registro do meu aprendizado em **Python**, construído aula a aula.

Aqui você encontra anotações comentadas, exemplos práticos e exercícios aplicados — tudo organizado de forma progressiva, do zero até funções.

> 💡 Ideal para quem está começando e quer um material limpo, prático e fácil de acompanhar.
